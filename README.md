1. Ephemera Weaver
2. Bid Spec Atlas
3. Funeral Price Pages

This repo is not the product implementation yet. It is the operating system for agents:
- product briefs
- stream specs
- task backlogs
- quality gates
- deploy review policy
- PR evidence requirements
- OpenClaw digest and approval cards
